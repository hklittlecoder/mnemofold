# Mnemofold

Mnemofold 是一个离线的长期记忆框架，用于个人代理和工作助手。它实现了记忆的**机械结构**——摄入、实体解析、承诺提取、时间有效性、巩固、冲突消解、衰减、检索、带引用的上下文打包、分诊评分、记忆状态追踪、确定性回放——而不依赖任何真实 LLM 的对话能力。

## 特性

- **工作事件基础**：类型化事件、JSONL 序列化、内容寻址 ID、合成时钟与时区安全的日分桶
- **存储基底**：追加式 SQLite 日志、校验和帧、模式迁移、崩溃安全事务、从日志重建投影
- **工作流图**：节点与类型化边、结构不变量、确定性序列化
- **摄入与情节分段**：线程/会议/日分段、实体解析、承诺与决策提取
- **时间模型**：区间有效事实、as-of 查询引擎、工作日历、截止日期算术
- **记忆分层**：工作集 / 情景 / 语义 / 程序剧本，晋升与降级规则
- **显著性评分**：透明的 NumPy 特征，可选的 PyTorch MLP
- **折叠（巩固）**：确定性夜间折叠、近重复合并、复发挖掘、折叠报告
- **冲突消解**：证据信任排序、确定性取代策略、矛盾审计
- **衰减与遗忘**：分层保留曲线、受保护记录、墓碑语义
- **检索**：BM25 倒排索引 + 实体图扩展、时间过滤、MMR 重排序、引用载荷
- **上下文包**：预算化选择（0/1 背包 DP）、任务配置打包剖面
- **承诺台账**：状态转移、逾期检测、推送、导出
- **收件箱分诊**：优先级评分、批量与安静时段规则、precision@k
- **会议准备**：证据收集、议程组装、带引用的数据包
- **站立会与周报**：确定性报告、自包含 HTML/SVG
- **剧本**：从重复工作流学习的程序、建议引擎、审批门控
- **工具与执行**：声明式工具规范、验证、幂等键、超时与重试
- **计划 DSL 与循环**：模式化 JSON 计划、DAG 验证、拓扑规划、感知-计划-行动-观察循环
- **审批队列**：待审批项、脚本化审批者角色、升级链
- **隐私与策略**：PII 检测、可逆/不可逆脱敏、分层规则、访问日志
- **删除语义**：遗忘权级联、墓碑、审计、复活属性测试
- **主动触发**：基于承诺/截止日期/陈旧线程的规则、冷却时间、去重
- **录制/回放**：校验和 JSONL、字节相同的回放、检查点/恢复
- **合成工作历史工厂**：种子角色、180 天合成历史、植入承诺与矛盾
- **评估框架**：端到端场景评分、切片与总评分卡
- **报告**：确定性 Markdown + 自包含 HTML + 自绘 SVG

## 安装

```bash
pip install -e ".[dev]"
```

可选 PyTorch 支持（CPU 版本）：

```bash
pip install -e ".[torch]" --extra-index-url https://download.pytorch.org/whl/cpu
```

## 快速开始

```bash
mnemofold demo --seed 42
```

## 开发

```bash
make build        # 构建 wheel
make test         # 运行快速测试
make test-all     # 运行全部测试（含慢测试）
make format       # 格式化
make format-check # 格式检查
make lint         # lint
make typecheck    # 类型检查
```
